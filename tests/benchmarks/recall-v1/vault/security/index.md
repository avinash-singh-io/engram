* [Defending Against Abuse](/security/rate-limit-abuse.md) - Throttling and challenging traffic to blunt credential stuffing and scraping.

* [Mutual TLS](/security/mtls.md) - Authenticating both client and server with certificates in mutual TLS.
* [OAuth2 Flows](/security/oauth2-flows.md) - Authorization-code, client-credentials, and device flows and when each fits.
* [Password Hashing](/security/password-hashing.md) - Storing credentials safely with slow, salted hashes like argon2 and bcrypt.
* [Secrets Management](/security/secrets-management.md) - Storing and rotating credentials in a vault instead of in code.
* [TLS Handshake](/security/tls-handshake.md) - Negotiating keys and authenticating a server during the TLS handshake.
