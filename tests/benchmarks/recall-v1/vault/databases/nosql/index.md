# nosql

## Concepts

* [Document Stores](/databases/nosql/document-stores.md) - Storing schema-flexible JSON documents with secondary indexes and denormalization.
* [Key-Value Stores](/databases/nosql/key-value-stores.md) - Constant-time get and put over an opaque value with no server-side querying.
* [Wide-Column Stores](/databases/nosql/wide-column.md) - Modeling queries first in Cassandra-style partition and clustering keys.
