# observability

## Concepts

* [Cardinality Explosion](/observability/cardinality-explosion.md) - How unbounded metric label values blow up a time-series database.
* [Distributed Tracing](/observability/distributed-tracing.md) - Propagating trace context across services to reconstruct a single request path.
* [Exemplars](/observability/exemplars.md) - Linking a metric bucket to a representative trace for fast drill-down.
* [Log Sampling](/observability/log-sampling.md) - Keeping a representative fraction of high-volume logs to control cost.
* [RED Metrics](/observability/red-metrics.md) - Rate, errors, and duration as the core signals for a request-driven service.
* [SLOs and SLIs](/observability/slo-sli.md) - Turning user-facing reliability targets into measurable indicators and error budgets.
* [Structured Logging](/observability/structured-logging.md) - Emitting machine-parseable key-value logs instead of free-form strings.
