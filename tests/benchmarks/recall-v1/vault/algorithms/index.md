# algorithms

## Concepts

* [Backtracking](/algorithms/backtracking.md) - Exploring a search tree and pruning branches that cannot lead to a solution.
* [Binary Search](/algorithms/binary-search.md) - Halving a sorted search space each step for logarithmic lookups.
* [Dynamic Programming](/algorithms/dynamic-programming.md) - Solving overlapping subproblems once by memoizing or building a bottom-up table.
* [Heaps and Priority Queues](/algorithms/heaps.md) - A binary heap giving logarithmic insert and extract-min operations.
* [KMP String Search](/algorithms/kmp-string-search.md) - Linear-time substring search using a prefix-function failure table.
* [Quickselect](/algorithms/quickselect.md) - Finding the k-th smallest element in expected linear time.
* [Reservoir Sampling](/algorithms/reservoir-sampling.md) - Sampling k items uniformly from a stream of unknown length.
* [Segment Trees](/algorithms/segment-trees.md) - Answering range queries and updates in logarithmic time.
* [Sliding Window](/algorithms/sliding-window.md) - Maintaining a moving range to answer subarray questions in linear time.
* [Topological Sort](/algorithms/topological-sort.md) - Ordering a directed acyclic graph so every edge points forward.
* [Tries](/algorithms/tries.md) - A prefix tree for fast string lookups and autocomplete.
* [Union-Find](/algorithms/union-find.md) - Near-constant-time connectivity queries with path compression and union by rank.
