| BUG-010 | The entire authoring surface was hidden from Obsidian | P1 | resolved | ad-hoc (v0.12.0) | Everything engram wrote lived in `.engram/`, and **Obsidian's file explorer ignores anything starting with a dot** — so `guardrails.md`, which the user is told to edit, and `.engram/skills/`, which the user is told to author, were both unreachable from the markdown editor engram is built around. | ENH-007 | `engram upgrade` and a vault provenance stamp | P2 | resolved | ad-hoc (v0.13.0) | Raised by the owner: one binary serves every vault, so all vaults move to a new version together and none could say what wrote it.
