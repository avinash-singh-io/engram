# Changelog — 2026-08

> Append-only. One line per change, newest last within a day.

## 2026-08-09

- **Design review (v2 architecture)** — 13-turn first-principles review of the product definition, primitives, and structure. Produced ADR-0018 … ADR-0031 on branch `feat/v2-architecture`.
- ADR-0018 — Engram redefined: a human knowledge system where the agent does the organizing. Explicitly **not** agent memory, **not** a context-window fix, **not** a better Obsidian.
- ADR-0019 — Primitives reduced to **Node + Edge**. `type`, `tags`, folders, MOCs, citations, attachments all shown to reduce to one of the two. Any structure = a choice of which edges get authored.
- ADR-0020 — **Adopt OKF v0.2**, superseding ADR-0002. Time and Provenance retired by the spec (`sources`, `generated`, `verified`, `stale_after`, `status`); engram adds only `supersedes`.
- ADR-0021 — Identity model: slug is identity, path is address, `aliases` in the moved file. Central redirect ledger rejected (multi-device write contention). Supersedes path-is-identity.
- ADR-0022 — Typed relations live in frontmatter, not markdown links. Closed-type rule: **no code, no closed type**. Closed set today is two (`supersedes`, `sources`). Amends ADR-0003.
- ADR-0023 — One human-chosen physical tree plus generated views. Corrects an earlier overclaim that structure is purely a view. Extends ADR-0006.
- ADR-0024 — Three-tier dependency inversion (core / policy / detail); adapters may only add affordances. Extends ADR-0011 and ADR-0015.
- ADR-0025 — Detection over configuration. Config cannot grant a capability; it only announces what is missing.
- ADR-0026 — Validation gates promotion, never capture. Amends ADR-0008's rejection behavior — mobile capture with no frontmatter is inbox, not an error.
- ADR-0027 — Relations extracted at **write time only**, never post-hoc. Four mitigation layers, two supplied free by OKF v0.2.
- ADR-0028 — Obsidian owns link rewriting; engram verifies only. Highest operational risk in the system, unrelated to any primitive.
- ADR-0029 — Derived state is never committed; regenerate, never merge.
- ADR-0030 — Boundaries are repositories, one per distinct set of humans who may see all of it. No visibility model, no lens, no permissions. Retires four of six originating requirements with zero code.
- ADR-0031 — Two evidence gates before graph investment, each able to end the project. Gate 1 threshold: <20% structural query traffic → stop.
- `specs/vision/problem-statement-v2.md` — new canonical problem statement; supersedes the framing in `project-charter.md`.
- `specs/planning/roadmap.md` — rewritten for the v2 line: Phase 7 (Evidence/Gate 1) → Phase 12 (Obsidian surface). **Phase 5 (Semantic Layer) cancelled**, superseded by Phase 11.
- TD-004 filed — the concept walker has no notion of a nested vault root, so a parent `reindex` would descend into a nested vault and publish its descriptions into a shared index.
- FEAT-003 / FEAT-004 filed — skills and guardrails as Tier-2 Agency concerns, post-v2.

## 2026-08-10

- **Architecture + intelligence pass.** Five ADRs (0032–0036) on branch `feat/v2-architecture`.
- ADR-0032 — Internal model (`core/model.ts`) + versioned codecs (`format/okf-v0_N.ts`) + a codec registry. Fixes a real OCP violation (`core/okf.ts` would be edited on every spec release) and a DIP violation (core types mirroring an external YAML schema). Also splits the fat `substrate` interface into narrow ports — `FileStore`, `Detector`, `Clock` — for interface segregation. Closed relation types become a registry, not a switch in the gate.
- ADR-0033 — `format(content, hints)` takes content, not a path. Capture is a durability step, not a prerequisite; `inbox/` is a buffer, not a pipeline stage. Found via the case "I hand raw notes to the agent and say format this" — there is no file to capture.
- ADR-0034 — Engram ships no encryption and no network. Encryption at rest is a substrate concern (full-disk, private repo, `git-crypt` on specific paths); an encrypted note is a note engram cannot help with. Names the threat that actually changed: **the agent is a network egress path**, answered by ADR-0030's separate repo, not by encryption.
- ADR-0035 — User memory is a second store at `.engram/memory/`, using ADR-0019's primitives unchanged: an observation is a node, a pattern is a node whose `sources` are the observations supporting it. Gitignored by default; `rm -rf` is safe by construction. High-volume events use a compact JSONL log; only distilled patterns become nodes.
- ADR-0036 — The intelligence loop: observe → distill → confirm → act → decay, mapped entirely onto `generated` / `verified` / `stale_after` / `sources` — no new fields. Inference ranked by *would a correct answer change behavior*: retrieval gaps, re-derivation, contradiction, staleness × intent, dead weight, then rhythm/calendar last (least differentiated, demos best). Constraints: proposals never facts, every recommendation cites evidence, rejection is a recorded signal, rate-limited, observation on by default and proaction opt-in, Rule 11 evaluator locked first.
- Roadmap extended to **Phase 14**. Phase 7 is now **dual-purpose** — Gate 1's instrumentation *is* the observation substrate the intelligence layer needs, so one build serves both. Phases 12–13 are Intelligence I/II; Phase 14 (Obsidian surface) is an independent lane that can move earlier.
- Connectors (calendar/events) recorded on the roadmap with an explicit warning: that is where engram becomes a productivity suite competing with much larger incumbents. Worth doing eventually, worth not doing accidentally.
- `specs/architecture/v2-overview.md` — new canonical architecture reference (12 sections: context incl. the bypass, modules/ports/codecs, data model, seven ops, the write gate, skills, guardrails, trust boundaries, read path, intelligence, surfaces, degradation). Constitutional under Rule 10.
- `specs/architecture/overview.md` marked **superseded** — it describes the v1 shape (single Concept primitive, path-as-identity, five required fields, untyped links), all four of which are replaced. Kept for history.
